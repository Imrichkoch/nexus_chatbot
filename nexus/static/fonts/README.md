# Bundled font

Archivo Black Regular is redistributed unmodified under the SIL Open Font
License 1.1; see `ArchivoBlack-OFL.txt` for the copyright and full license.
Source: https://github.com/google/fonts/tree/main/ofl/archivoblack

The font is served locally so the application does not contact third-party font
services. Body and monospaced text use the CSS system fallbacks.
